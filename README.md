# MORPH research workspace

Local research project based on [MORPH: Model of Object Representation and Predictive Homomorphisms](https://spencerbug.github.io/blog/morph/).

- [Architecture capture](architecture/capture.md): article commitments, information boundaries, interfaces, open questions and provisional choices.
- [Active specification](SPEC.md): E0, a small controlled rotation-prediction experiment.
- [Experiment ledger](Experiments.md): configurations, results, failures and next decisions; currently design-only.
- [Current state and resume instructions](STATUS.md).
- [Agent operating instructions](AGENTS.md).

No model has been implemented or evaluated yet. All development stays in this project.
